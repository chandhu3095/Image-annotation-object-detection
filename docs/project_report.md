# Mini Project Report: Image Annotation for Object Detection

## Objective
Practice object identification, bounding-box annotation, class assignment, and annotation quality review.

## Dataset
- 12 synthetic street-scene images
- Image size: 640 × 360 pixels
- Five classes: person, car, truck, bus, motorcycle
- Starter labels: YOLO normalized bounding-box format

## Workflow
1. Inspect images and identify target objects.
2. Review or edit bounding boxes in CVAT/LabelImg.
3. Check class consistency and box tightness.
4. Validate label files and coordinates.
5. Summarize annotation counts and quality issues.

## Scope and limitation
This is a synthetic practice dataset generated for learning. It is not a production dataset and does not represent paid annotation work. Manually review the labels before using them in any model-training workflow.
